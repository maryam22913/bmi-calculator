# 🌟 Smart BMI Calculator

A modern, responsive, and beautiful Body Mass Index (BMI) calculator web app.

## ✨ Features
- 🔄 **Metric & Imperial Units:** Calculate using kg/cm or lbs/ft-in.
- 🎨 **Visual BMI Gauge:** Real-time pointer showing your health zone.
- 💡 **Personalized Health Tips:** Dynamic suggestions based on calculated BMI score.
- 📱 **100% Responsive:** Looks stunning on mobile, tablet, and desktop screens.
- ⚡ **Zero dependencies:** Built purely with clean HTML5, CSS3, and modern JavaScript.
